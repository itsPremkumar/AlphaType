# 📱 AlphaType - The Alphabetical Android Keyboard

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Android](https://img.shields.io/badge/Platform-Android-green.svg)]()

AlphaType is a custom Android input method designed for simplicity, accessibility, and learning. Unlike standard QWERTY keyboards, AlphaType arranges letters in alphabetical order (A–Z), making it ideal for beginners, kids, and elderly users.

## ✨ Key Features

- **🔤 Alphabetical Layout**: Intuitive A-Z arrangement for easy letter finding.
- **🔊 Voice Feedback**: High-quality Text-to-Speech (TTS) for every key press.
- **🍎 Learning Mode**: Integrated hints (e.g., "A for Apple") with visual and audio feedback.
- **🔁 Layout Switching**: Seamlessly toggle between ABC, QWERTY, and Numeric layouts.
- **🎨 Premium UI**: Modern, high-contrast design with smooth animations and haptic feedback.
- **🔒 Privacy First**: 100% offline. No data collection, no internet access required.

## 🚀 Getting Started

### Prerequisites
- Android Studio Flamingo or newer
- Android SDK 21+ (Compatible with Android 5.0 and above)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/username/alphatype.git
   ```
2. Open the project in **Android Studio**.
3. Build and Run the app on your device or emulator.

### Enabling the Keyboard
1. Go to **Settings** -> **System** -> **Languages & input**.
2. Select **On-screen keyboard** -> **Manage on-screen keyboards**.
3. Toggle on **AlphaType Keyboard**.
4. Open any app and select AlphaType as your default input method.
